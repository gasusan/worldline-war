# WORLDLINE WAR - Online Prototype

ブラウザで2人対戦できるWeb版プロトタイプです。

## 起動
1. Node.js 18+ を用意
2. `npm install`
3. `npm start`
4. ブラウザで `http://localhost:3000`
5. 片方がルームを作成し、表示された5文字コードを相手へ共有

## オンライン公開
Render / Railway / Fly.io / VPSなど、Node.jsのWebSocketを扱えるホスティングへこのフォルダを配置し、`npm install && npm start` を実行してください。
HTTPS環境ではWebSocketも自動的にWSSになります。

## 実装済みの核
- 3レーン×7マスの共有盤面
- 初手6枚
- 先攻1ターンドローなし
- 1ターン1資源配置
- Ready / Used資源
- コスト支払い
- 1ターン2回進軍
- 配置酔い
- レーン内戦闘
- 攻撃→反撃→同時墓地
- 生存した進軍側の1マス後退
- 本拠地ダメージとダメージ時ドロー
- 山札切れ敗北
- 施設1枚・罠
- 近代王国/孤独王国/サイバー連邦/野生王国/共通カードのデータ
- ルームコード式2人オンライン対戦

## 注意
これは「遊べる土台」のMVPです。カードごとの裁定を完全自動化するには、今後ターゲット選択UI、効果スタック、墓地効果の優先権、空中/対空の詳細、マロロ/アルフォン/進化/咆哮などの全裁定をカードエンジンへ段階的に追加する必要があります。
